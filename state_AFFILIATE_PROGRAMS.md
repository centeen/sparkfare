## Status Legend

- **Applied** — application submitted, awaiting network/advertiser decision
- **Pending** / **Pending Approval** — same as Applied, used interchangeably for submitted-and-waiting
- **Paused (platform-side)** — the program itself is temporarily inactive or unfindable; not a Sparkfare-side decision, revisit later
- **Holding, deliberately** — a Sparkfare-side choice to delay applying until a precondition is met
- **Not Started** — nothing submitted yet, no blocker
- **Not Researched** — candidate identified but no program verification done yet
- **Blocked** — cannot proceed until a named external condition (usually Legal) clears
- **Excluded** — decided dead end, do not revisit
